# ADR-006 — RN/Cocos bridge

## Status
Proposed protocol v1, native verification pending. Recorded2026-09-08. This records planning authorization, not a successful native build.

## Context and evidence
Native callbacks can be duplicated/reordered after lifecycle changes. A single protocol supports Android/iOS harnesses and web stubs. See [evidence](../03_EVIDENCE_LEDGER.md), [unknowns](../04_UNKNOWNS_REGISTER.md) and [architecture](../technical/01_ARCHITECTURE.md).

## Decision
Typed versioned JSON envelopes, session/generation guards, request IDs, per-message payload validation and idempotent operation results.

## Consequences and alternatives
No per-frame messages. Purchases/ads are reserved interfaces only. Exact thread scheduling and exported APIs are spike outputs.

## Verification and revisit trigger
Complete [PHASE_03_NATIVE_INTEGRATION_SPIKE](../../plans/PHASE_03_NATIVE_INTEGRATION_SPIKE.md), attach acceptance results and update this ADR if measured evidence invalidates its premises. Do not rewrite historical evidence to make the selected approach appear confirmed.
