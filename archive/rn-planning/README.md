# Историческое планирование RN/Skia — не активные инструкции

Документы сохранены для деталей механик, обоснований, измерений и истории решений. Пользователь перешёл на самостоятельный Cocos runtime; RN/Expo/Skia, ADR-007, прежний DAG и release gates **не управляют текущей разработкой**. Статусы старых задач оставлены как исторические факты, не переобозначены как выполненные.

Актуальные документы: [README](../../README.md), [AGENTS](../../AGENTS.md), [индекс](../../docs/00_INDEX.md), [Cocos DEVELOPMENT](../../cocos-spike/DEVELOPMENT.md).

- docs/ — прежние подробные спецификации, экраны, ограничения исследования, архитектурные решения.
- plans/, tasks/, data-spec/ — прежние планы, статусы и схемы.
- Корневые отчёты — прежние milestone/spike документы.

Архивные ссылки/пути отражают старое расположение; некоторые не разрешаются из этого каталога. Полное прежнее дерево с исходниками, генераторами, проверками и отчётами сохранено в Git на `3b81e20` (последний коммит до очистки). Используйте `git show 3b81e20:путь`, а не восстанавливайте старый runtime поверх текущего. Для shallow clone сначала `git fetch --unshallow`.

ТЗ остались в docs/tz/. Доказательства Figma/референса — в analysis/figma/ и analysis/reference/. Из рабочего дерева удалены RN-приложение, его копия core, Expo-хост/зависимости, экспериментальный RN↔Cocos мост и повторяющиеся RN QA-отчёты.
