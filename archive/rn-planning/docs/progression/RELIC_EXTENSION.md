# Relics — delivery rule relic-v1 (PROPOSED)

Figma SCREEN-005 defines the 16 visual identities, 4×4 collection, UR/SR/SS
ornaments and Open x1 (100 gold) / Open x10 (100 gems) controls. Those displayed
costs are explicitly adopted as our product rule, not measured reference balance.

Each draw uniformly selects one of the 16 entries. A single atomic command debits
currency, updates permanent collection counts, saves reward RNG and a stable
receipt, and retains the latest batch for reopening after restart. No ad, pity,
real-money purchase or rarity-weight claim. Repeated command cannot reroll.

Relics passively improve all heroes: alternating attack/HP entries grant 2% of
base stat per collected copy, capped at 20 effective copies per relic. Counts
continue to accumulate safely and stay visible after the cap; nothing is removed.
Item details explain the actual effect and ownership. All 16 source visuals remain
visible as collection previews, with counts indicating ownership. Presentation
opens only after durable commit; its animation cannot grant items or stats.
