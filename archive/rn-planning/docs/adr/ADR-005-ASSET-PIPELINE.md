# ADR-005 — Asset pipeline

## Status
Accepted planning contract. Recorded2026-09-08. This records planning authorization, not a successful native build.

## Context and evidence
351 source rasters need traceable classification and bounded runtime residency. A screenshot cannot substitute for constructed controls. See [evidence](../03_EVIDENCE_LEDGER.md), [unknowns](../04_UNKNOWNS_REGISTER.md) and [architecture](../technical/01_ARCHITECTURE.md).

## Decision
Immutable source fig; semantic registry with resolution variants, reviewed pivots/trim/insets, grouped atlases and per-route loading.

## Consequences and alternatives
Rights/fonts, 9-slice calibration and runtime downscaling remain gates. Do not automatically chop flattened characters.
